# Study Timer - Focus Timer for Students

A simple mobile-friendly study timer app for students to stay focused using Pomodoro-style sessions.

## Features
- Start / Pause / Reset timer
- Focus, Short Break, and Long Break modes
- Shows minutes + seconds in real-time
- Calm alarm that keeps ringing until Done is clicked
- Session counter and History log
- Works on mobile and desktop, no installation needed

## How to Run
1. Download or clone this repository
2. Open `index.html` in any browser
   OR use VS Code > Right-click `index.html` > Open with Live Server
3. Choose a mode and click Start

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage for History
